# SubTrack 4.0

Обновление найденного исходника SubTrack v3. Сохранены стеклянные карточки, логотип, плавающая анимированная панель, русская/английская локализация, API курсов и ключ локального хранилища `subtrack.v1`.

## Запуск через VS Code и Android Studio

1. Распакуйте ZIP и откройте папку SubTrack-4 в VS Code.
2. В терминале этой папки выполните:

```sh
npm install
npx expo start
```

3. Запустите Android-эмулятор в Android Studio (Device Manager), затем нажмите `a` в терминале Expo. Для SDK 54 понадобится совместимая версия Expo Go. Если её нет, используйте нативную сборку `npm run native:android` с настроенными Android SDK/JDK. При необходимости выполните `npx expo install --fix`.
4. Для браузера нажмите `w` или выполните `npm run web`. Для очистки кеша: `npx expo start --clear`.

Xcode не нужен для Android. Для локальной нативной сборки iOS SDK 54 нужен более современный Xcode, чем 15.2 на macOS Ventura. Expo Go на iOS и Android должен поддерживать выбранный SDK.

## Expo Snack

Основной код находится в `App.js`. Его можно вставить в Snack, выбрав SDK 54, если этот SDK доступен. Добавьте все импортируемые зависимости из `package.json`. Веб-превью не подтверждает работу нативных API; при несовместимости `expo-file-system/legacy` или нативных модулей используйте полноценный проект из ZIP. Для проверки нативных функций рекомендуется development build. Не стирайте старую версию до сохранения резервной копии.

## Что реализовано

- Главная: среднемесячная и годовая стоимость, месячный лимит, ближайшие оплаты, прогноз расчётного периода, категории.
- Подписки: каталог популярных сервисов, логотипы с резервными иконками, свой сервис, поиск, сортировки и комбинированные фильтры, редактирование свайпом или долгим нажатием.
- Карточка подписки: тариф, стоимость, исходная валюта, период, дата, способ оплаты (только текстовая метка), пробный период, напоминания, автопродление как метка, заметки, ссылка на сайт, сравнение с указанной ценой годового тарифа, изменение цены, ручная запись платежа, пауза, архив, отмена удаления.
- Аналитика: календарь с переходом между месяцами, график зарегистрированных платежей, круговая диаграмма, категории, способы оплаты, сравнение месяцев, прогноз, архив. Графики используют только реальные записи, сделанные пользователем; исторические суммы пересчитываются по текущему курсу. Архив и пауза не отменяют подписки у поставщика.
- Валюты: оригинальные цены не меняются, кросс-курсы, кеш, справочные исходные курсы при первом запуске, округление отображения, сообщение об ошибках. Недоступные курсы не подменяются вымышленными. Некоторые аналитические суммы могут быть частичными, если отсутствуют курсы.
- Настройки: системная/светлая/тёмная тема, два языка, свои категории, способы оплаты, расчётный день, уведомления, тактильный отклик, биометрическая блокировка, локальный JSON-бэкап и восстановление, CSV истории, знакомство с приложением, сведения о конфиденциальности.
- Нативные уведомления: расписание локальных напоминаний по активным подпискам, пробным периодам и бюджету; планируются ближайшие 90 дней (до 60 событий) при изменениях/запуске приложения. Нужны разрешения системы. Это прогнозы, а не подтверждения платежей. При длительном отсутствии запусков расписание не продлевается автоматически.

## Проверки и ограничения

- Проверен синтаксис JSX через TypeScript parser, 11 автоматических проверок логики (даты 31-го числа, високосный год, еженедельный и квартальный циклы, валютная конвертация, отсутствующий курс, проверка дат).
- Зависимости подобраны по официальному списку Expo SDK 54: https://github.com/expo/expo/blob/sdk-54/packages/expo/bundledNativeModules.json
- Установить npm-зависимости в среде подготовки архива не удалось из-за отсутствия доступа к registry.npmjs.org. Metro, Android/iOS сборки, реальные разрешения, доставка уведомлений, Face ID и live API на устройстве ещё не проверены. Возможны исправления по результатам запуска.
- Нативные виджеты домашнего экрана, облачная синхронизация между устройствами, публикация в магазинах и полноценные UX-тесты не реализованы. Для виджетов понадобятся нативные расширения, для синхронизации — отдельно выбранное хранилище и стратегия защиты данных. В этом обновлении сохранён AsyncStorage вместо миграции на SQLite, навигация осталась собственной вместо Expo Router, анимации — Animated вместо Reanimated, перевод — встроенный словарь. Это не требует менять существующий формат данных без необходимости.
- Биометрия блокирует интерфейс, но не шифрует AsyncStorage. JSON-резервные копии не зашифрованы. Логотипы запрашиваются у внешнего сервиса Google по доменному имени, цены и платёжные данные туда не отправляются. Курсы получаются из ExchangeRate-API. Веб-превью не поддерживает нативные уведомления и биометрию.
- При замене версии в том же приложении/контейнере данные читаются из прежнего ключа. Другая сборка, другой Snack или новый пакет могут иметь отдельное хранилище, поэтому сохраните резервную копию.
