## Overview

SubTrack brings recurring payments, spending insights and upcoming renewals into one minimal interface. Keep track of what you pay for, understand your expenses and plan your next payment.

## Features

- Subscription management and renewal calendar
- Monthly and yearly spending insights
- Multi-currency support with exchange rate updates
- Budgets, payment history and reminders
- Light, dark and system appearance
- English and Russian localization
- Local storage, backups and CSV export

## Getting started

```bash
git clone https://github.com/Gxmrr/SubTrack.git
cd SubTrack
npm install
npx expo start
```

Press `w` to open the web app, `a` for Android or `i` for the iOS simulator on macOS.

## Built with

React Native · Expo · JavaScript · AsyncStorage

## Privacy

Subscription data is stored locally. No bank connection or account is required. Exchange rates and service icons are retrieved from external providers.

Native reminders and biometric access require a compatible mobile build and device permissions. Backups are not encrypted.
